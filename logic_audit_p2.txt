20. `emulate` Tool
    - `snippet`:
      - *Limit*: 1000 steps.
      - *Logic*: `idaapi.decode_insn`, `get_bytes`, `generate_disasm_line`.
      - *Issue*: Does not actually *emulate* (execute) the code. It just "traces" static disassembly linearly. It handles simple jumps (`JMP`) but falls through conditional jumps.
      - *Misleading*: The doc says "Emulate code", but implementation says "Static trace".
    - `appcall`:
      - *Dependency*: Requires `ida_dbg.is_debugger_on()`. Good check.
      - *Safety*: `Appcall` executes code in the debugged process. High risk but expected.

21. `export` Tool
    - `listing`:
      - *Limit*: 10000 lines. Safe.
    - `binexport`:
      - *Dependency*: `ida_loader.load_and_run_plugin("binexport", 0)`. Depends on external plugin.

22. `history` Tool
    - `snapshot`:
      - *Implementation*: Saves a JSON metadata file.
      - *Limitations*: "actual IDB backup requires manual copy". It doesn't actually copy the IDB. This is misleading for an "undo/snapshot" feature if users expect full state restore.

23. `strings_xref` Tool

24. `entropy` Tool
