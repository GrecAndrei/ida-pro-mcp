# IDA Pro MCP v1.0.0a3

The third alpha release makes live operation discovery the single tool-surface
contract and adds whole-session binary diff triage for patch review.

### Highlights

- **Live discovery as the contract**: Removed the static agent-skill and
  operation-reference snapshots that could drift from the exposed surface.
  `tools/list` enumerates every one of the 109 strict-schema `ida_*`
  operations, and `ida_help` returns exact arguments plus an example from the
  running server — nothing generated to go stale, and harnesses can never see
  skills for a tool set that is not exposed.
- **Whole-session binary diff triage**: `ida_diff_sessions` inventories two
  open sessions, automatically matches functions by stable symbol, normalized
  content, address, and bounded fuzzy similarity, then ranks modified pairs
  with added and removed calls, constants, unmatched functions, and scan
  coverage.
- **Streamlined installer**: The Codex / Claude Code / OpenCode skill phases
  and their `--skills-mode`, `--install-skills`, and `--only skills` options
  are removed. The installer configures runtimes, clients, shell shims, and
  signature packs; harnesses discover the surface live.
- **Verified release gates**: 6223 offline tests pass, plus Python 3.11/3.12
  standalone CI, CodeQL, immutable-action-pin checks, Rizin validation, and
  schema-integrity verification of the 34-tool legacy surface and the 109
  operation catalog.

### 🚀 Instant Auto-Installation (No Manual Extraction Needed)

#### Linux & macOS (One-Line Install)

```bash
curl -fsSL https://github.com/GrecAndrei/ida-pro-mcp/releases/download/v1.0.0a3/install.sh | bash
```

*Or download `install.sh` from the release assets below and run `./install.sh`.*

#### Windows (One-Click Install)

Download **`install.bat`** from the release assets below and **double-click it**. It auto-detects Python, configures IDA Pro, and sets up your AI coding tools.

#### Standalone Executable

Download the native binary for your architecture from the release assets below (e.g. `ida-pro-mcp-installer-linux-x86_64`), make it executable (`chmod +x`), and run it directly.

---

### 📦 Manual / Offline Installation

If installing offline or in an air-gapped environment:
1. Download the `ida-pro-mcp-1.0.0a3-bundle.tar.gz` (or `.zip`) from the assets below.
2. Extract the archive and execute:
   ```bash
   python install.py --auto
   ```

The bundle does not include IDA Pro, proprietary files, model weights, or
credentials.
