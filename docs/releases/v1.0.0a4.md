# IDA Pro MCP v1.0.0a4

IDA Pro MCP v1.0.0a4 provides deterministic IDA analysis with explicit, bounded Jev/custom advice and a stronger host-to-IDA security boundary.

### Highlights

- **Explicit host-side intelligence**: Select Jev, a configured custom provider, or disabled mode. The host performs bounded query expansion, classification, and candidate ranking; no implicit local, Gemini, or native-model fallback exists, and IDA child processes do not inherit provider credentials or configuration.
- **Blackboard advice runs in the background**: After finding changes, an optional host worker recommends finding lanes and ranks only xrefs and relations already present in stored evidence or graph snapshots. It uses bounded signatures and metadata, and never writes findings or links.
- **Shared response detail is part of the public contract**: Every strict `ida_*` operation now accepts `detail="triage"|"normal"|"deep"`; omitting it keeps the normal budget. Truncation metadata uses `_continue.fields` as a descriptor list and retains the former mapping under `fields_by_path`.
- **Safer, smaller tool surface**: Binary opens report bounded lifecycle states; address handling and raw-image workflows have additional validation. The obsolete Rizin sidecar and unused firmware operations were removed; clients using `ida_r2_*` or `ida_fw_*` must update. Legacy firmware compatibility remains available. The default surface exposes 102 operations discoverable with `tools/list` and `ida_help`.

### Compatibility and rollback

The 102 operation names remain unchanged. `detail` is optional and additive;
clients that do not send it continue to get the normal response budget. Clients
that read `_continue.fields` as a path map must use each descriptor's `path`
and read the compatibility copy from `fields_by_path` when needed.

To roll back to v1.0.0a3, reinstall that version and omit the new `detail`
argument. The advisory snapshot uses the existing Blackboard machinery tables;
the alpha change does not migrate finding rows or change their lifecycle,
evidence, provenance, conflicts, or explicit links.

### 🚀 Instant Auto-Installation (No Manual Extraction Needed)

#### Linux & macOS (One-Line Install)

    curl -fsSL https://github.com/GrecAndrei/ida-pro-mcp/releases/download/v1.0.0a4/install.sh | bash

Or download `install.sh` from this release and run `./install.sh`.

#### Windows (One-Click Install)

Download `install.bat` from this release and double-click it. It auto-detects Python, configures IDA Pro, and sets up supported MCP clients.

#### Standalone Executable

Download `ida-pro-mcp-installer-linux-x86_64` from this release, make it executable with `chmod +x`, and run it.

---

### 📦 Manual / Offline Installation

1. Download `ida-pro-mcp-1.0.0a4-bundle.tar.gz` or `ida-pro-mcp-1.0.0a4-bundle.zip`.
2. Extract the archive and run:

       python install.py --auto

The bundle does not include IDA Pro, proprietary files, model weights, or credentials.
