# IDA Pro MCP v1.0.0a2

The second alpha release adds deterministic cross-session function comparison
and hardens the HTTP, testing, and native-build release paths.

### Highlights

- **Cross-session function comparison**: Compare decompiled functions from two
  live IDA sessions with bounded unified diffs and raw/normalized similarity.
- **Security-aware normalization**: Suppresses IDA-generated naming and
  whitespace noise while preserving numeric constants such as bounds and masks.
- **Production hardening**: Rejects control characters before reflecting CORS
  origins and validates cloud endpoint hosts structurally.
- **Verified release gates**: 108 strict-schema operations, real IDA 9.3/9.4
  tests, Python 3.11/3.12 offline coverage, Rizin validation, and the pinned
  native backend smoke build.

### 🚀 Instant Auto-Installation (No Manual Extraction Needed)

#### Linux & macOS (One-Line Install)

```bash
curl -fsSL https://github.com/GrecAndrei/ida-pro-mcp/releases/download/v1.0.0a2/install.sh | bash
```

*Or download `install.sh` from the release assets below and run `./install.sh`.*

#### Windows (One-Click Install)

Download **`install.bat`** from the release assets below and double-click it.

#### Standalone Executable

Download **`ida-pro-mcp-installer-linux-x86_64`**, make it executable with
`chmod +x`, and run it directly.

---

### 📦 Manual / Offline Installation

1. Download `ida-pro-mcp-1.0.0a2-bundle.tar.gz` or the `.zip` asset.
2. Extract it in the offline environment.
3. Run:

   ```bash
   python install.py --auto
   ```

The bundle does not include IDA Pro, proprietary files, model weights, or
credentials.
